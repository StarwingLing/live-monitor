# bili-monitor 教程导览

B站直播间数据监控系统：采集（弹幕/礼物/SC/舰长/同接）→ SQLite 存储 → FastAPI 网页展示，部署在阿里云 ECS 上 7×24 运行。

## 项目一句话

监控约 10 个 B站直播间，记录每次直播的弹幕、礼物收入、SC、舰长、同接曲线、观众构成与用户分层，通过网页查看，房间可在页面上增删。

## 快速上手

```bash
# 本地运行（两个终端）
uv run python -m bili_monitor.capture.main          # 终端1：采集服务
uv run uvicorn bili_monitor.web.app:app --port 8001  # 终端2：Web 服务
# 浏览器打开 http://127.0.0.1:8001/
# 本地 config.toml 的 admin_password 留空 = 调试模式不强制登录；填值则与线上一致
```

访问地址：`http://<你的服务器IP>/bili-monitor/`（应用内登录页：管理员账号 / 游客码；初始凭据在首次启动后查看服务器上的 `data/web_credentials.txt`）
